One consistent style

Sodium supplies square corners, thin rules, neutral surfaces, and a restrained yellow accent. Prose stays in sans; interface labels and code use mono.

What works offline?

The embedded styles, fonts, diagram, table, and disclosure work without a network connection. Source links open external documentation when connectivity is available.
